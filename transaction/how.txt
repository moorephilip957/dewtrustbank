9. VERY IMPORTANT — Use Atomic Transactions

Critical for banking systems.

from django.db import transaction

with transaction.atomic():

    account.balance -= amount
    account.save()

    TransactionHistory.objects.create(
        user=user,
        transaction_type="local_transfer",
        amount=amount,
        status="success"
    )

This prevents broken balances.

6. IMPORTANT

Forms should ONLY:

validate
clean data

They should NOT:

debit balances
create ledger entries
send money

Do those in:

services.py
utils.py
processors.py

Example:

process_local_transfer(
    user=request.user,
    form=form
